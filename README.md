# Фокус

Небольшой сайт на React: таймер для работы и перерывов, список задач и сохранение задач в localStorage. Адаптирован для телефона и компьютера. Сервер и аккаунт не нужны.

## Запуск

Нужен Node.js 22.12 или новее.

```sh
npm install
npm run dev
```

## Сборка

```sh
npm run build
npm run preview
```

Готовые файлы появятся в `dist/`. Относительные пути позволяют размещать сборку в подпапке, в том числе на GitHub Pages. Внешний шрифт необязателен: при отсутствии сети используется системный.

## Структура

- `src/main.jsx` — таймер, задачи и интерфейс.
- `src/style.css` — стили и мобильная версия.
- `public/favicon.svg` — иконка сайта.
- `vite.config.js` — настройки сборки.

Таймер учитывает фактически прошедшее время при возвращении на вкладку. После перезагрузки таймер сбрасывается, задачи остаются в том же браузере. Если хранилище недоступно, сайт сообщает об этом.
